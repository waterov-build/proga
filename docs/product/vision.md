# Product Vision

## Problem
Enduro mountain bike races use timed segments. Riders rely on separate GPS devices and manual timing. Results are slow, error-prone and require a large marshal workforce.

## Solution
An end-to-end platform that:
- Automatically detects segment start/finish on a Garmin device using GPS geo-fencing
- Uploads results via Bluetooth to an Android companion app
- Syncs to a cloud backend for live leaderboards
- Provides an AI-powered race-ops layer for organisers

## Target Users
| User | Need |
|------|------|
| Rider | See personal segment time on wrist, review results post-race |
| Organiser | Build segments, publish event packs, monitor live results |
| Marshal | Exception handling when GPS is disputed |
